# 💪 腕ずもうランク — 「喧嘩より公式戦」

腕ずもうの**地域ランキング**と、**勝つほど育つトレーディングカード**を組み合わせた対戦記録サービスのプロトタイプです。
「強さを証明したい」という気持ちを、路上の喧嘩ではなく**安全で公式な対戦**へ向けることを目指しています。

🌐 デモ: https://birdnnjjhiroselittle.github.io/udezumo-rank/
（「👤 選手登録」タブの「サンプルデータを入れる」を押すと、すぐにランキングとカードを試せます）

## できること
- **地域ランキング**：全国／都道府県／市区町村、右腕・左腕・総合、年間・通算で切り替え
- **対戦の記録**：スマホで証拠動画を撮影 → 勝者を選ぶ → 両者が合意 → 立会人が承認
- **検証レベルで重みが変わる戦闘力**（Elo方式）

  | レベル | 条件 | ポイントの重み |
  |---|---|---|
  | Lv0 | 自己申告のみ | 0（記録だけ） |
  | Lv1 | 両者がアプリで合意 | ×0.3 |
  | Lv2 | ＋証拠動画 | ×0.7 |
  | Lv3 | ＋認定立会人の承認 | ×1.0 |
  | Lv4 | 公式大会の結果 | ×1.2 |

  同じ相手との連戦は重みが下がるので、なれあいでポイントを稼げません。
- **育つトレカ**：勝つほど N → R → SR → UR → LEGEND に進化。称号（地域1位など）、撃破記録、交換したカードも載る
- **SNS連動**：カードを画像で保存、𝕏などにシェア（#喧嘩より公式戦）
- **反暴力の仕組み**：登録時に反暴力の誓約。暴力行為が確認されたらカードを凍結

## 反暴力の考え方
1. **強さを証明する正規ルートを作る** ― 公式戦で勝てばランキングとカードで認められる
2. **失うものを持たせる** ― 育てたカードは、路上の暴力で凍結・剥奪される
3. **礼儀を数値にする** ― 対戦相手からの「フェアプレー値」がカードに載る
4. **敬意の儀式** ― 試合後に握手してカードを交換する
5. **お金と勝敗を切り離す** ― 本人のカードは売買不可（名誉の証）。賭博・八百長の動機を作らない

## なぜ腕ずもうから始めるのか
- 数秒で決着し、勝敗が誰の目にも明らか。短い縦型動画がそのままSNSの拡散材料になる
- 打撃がなく安全。台1つでジム・バー・イベント会場どこでもできる
- 日本には全国共通のランキングがまだない

## 広がり方（ロードマップ）
| 段階 | 対象 | 理由 |
|---|---|---|
| 1 | 💪 腕ずもう | 勝敗が明確・安全・SNS映え。地域から始める |
| 2 | 🥋 柔術 | **タップアウト**で決着するため判定が明確で不正しにくい。競技団体の**公式アプリ**として提案 |
| 3 | 🎱 ビリヤード・🎾 テニス・卓球など | 日常的に対戦があり、ランキングの需要が大きい |
| 4 | 🏅 あらゆる対戦 | 共通の「対戦ID」と「戦闘力カード」で競技をまたいでつながる |

※ ボクシングなどの打撃系は、反則（裏拳・後頭部への打撃など）との境目が一般の人には分かりにくく、動画での判定も難しいため、当面は対象外とします。格闘技の柱は柔術にします。

## 使い方
`index.html` をブラウザで開くだけ（サーバー・APIキー不要）。データはブラウザ内（localStorage）に保存されます。

## 今後の構想
- 各自のスマホでQRコードを読み合って対戦を開始し、それぞれが合意（なりすまし防止）
- 証拠動画をAIで確認（人数・顔・時刻・場所・反則の検出）
- 立会人の信用スコア、不正パターンの自動検出
- 戦闘力の計算を Glicko-2 に（強さの「確からしさ」も扱える）
- 自治体・警察・ジムと組んだ「喧嘩より公式戦」大会、実物カードの印刷（ジム・ゲームセンター）
- 柔術団体との連携（大会結果の取り込み＝Lv4）
